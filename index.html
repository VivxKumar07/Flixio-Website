Under the Hood

Dual playback engines & unified source runtimes.

Inspect how Flixio combines AndroidX Media3, libmpv, CloudStream 3, QuickJS, and Telegram TDLib into one cohesive client.

Dual Engine: AndroidX Media3 (ExoPlayer) + libmpv

Use Media3 for battery-friendly hardware MediaCodec playback and Picture-in-Picture, or switch to libmpv whenever a stream uses Hi10P, complex MKV chapters, multi-track audio, or intricate ASS/SSA typography via libass.

SECONDARY ENGINE MPV (libmpv) + libass subtitles

What Flixio is not.

Flixio is strictly a client-side media player and catalog interface for Android. It does not host, upload, index, or distribute any movies, series, or streams. All playback comes exclusively from addons, repositories, Telegram chats, or debrid accounts configured by the user.

Flixio builds upon open-source software including Nuvio Mobile (GPLv3), CloudStream 3 (GPLv3), AndroidX Media3 (Apache 2.0), mpv / MPVKit (GPLv2+ / LGPLv2.1+), libass, QuickJS, and TDLib (BSL-1.0). Flixio uses the TMDB API but is not endorsed or certified by TMDB.
